# Сайт «Логопед Пивовар Кристина Сергеевна»

Готовая статическая версия для GitHub Pages.

## Публикация

1. Создайте на GitHub публичный репозиторий с названием `logoped-pivovar`.
2. Распакуйте архив и загрузите в корень репозитория всё содержимое папки.
3. Откройте `Settings → Pages`.
4. В разделе `Build and deployment` выберите `Deploy from a branch`.
5. Укажите ветку `main`, папку `/(root)` и нажмите `Save`.
6. Через несколько минут GitHub покажет общедоступный адрес сайта.

Файл `.nojekyll` необходим для корректной загрузки встроенных шрифтов.
